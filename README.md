# WeCare Hospital

WeCare Hospital is a web-based hospital management and appointment booking project.

## Technologies
- React
- TypeScript
- Vite
- Node.js
- Express.js
- MySQL

## Features
- User authentication
- Doctor applications and verification
- Doctor listings
- Appointment booking
- Admin dashboard
- Support tickets

## Development

Install dependencies:

```bash
npm install
```

Start the frontend:

```bash
npm run dev
```

Start the backend in a separate terminal:

```bash
npm run server
```
